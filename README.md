# Primitive DB

Примитивная база данных, реализованная на Python. Проект демонстрирует управление зависимостями через `uv`, работу с файловой системой (JSON), обработку исключений через декораторы и подготовку пакета к публикации на PyPI.

## Установка и запуск

Проект использует пакетный менеджер `uv`.

1.  **Клонирование репозитория:**
    ```bash
    git clone <ссылка_на_ваш_репозиторий>
    cd project#2_<фамилия>_<группа>
    ```

2.  **Установка зависимостей:**
    ```bash
    uv sync
    ```

3.  **Запуск базы данных:**
    ```bash
    uv run database
    ```

## Управление таблицами

Команды для работы со структурой базы данных:

*   `create_table <имя> <кол1:тип> <кол2:тип>` — создать таблицу. Поддерживаемые типы: `int`, `str`, `bool`. Столбец `ID:int` добавляется автоматически.
*   `list_tables` — показать список всех таблиц.
*   `drop_table <имя>` — удалить таблицу (программа запросит подтверждение `[y/n]`).
*   `info <имя>` — показать структуру таблицы.

**Пример:**
Введите команду: create_table users name:str age:int 
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int


## CRUD-операции (Работа с данными)

Команды для манипуляции записями:

*   `insert into <имя> values (<знач1>, <знач2>...)` — добавить запись.
*   `select from <имя> [where <столбец> = <значение>]` — прочитать записи.
*   `update <имя> set <столбец> = <значение> where <столбец> = <значение>` — обновить запись.
*   `delete from <имя> where <столбец> = <значение>` — удалить запись (программа запросит подтверждение `[y/n]`).

**Пример:**
* Введите команду: insert into users values ("Ivan", 25)
  * Запись с ID=1 успешно добавлена в таблицу "users". 
  * Функция 'insert' выполнилась за 0.0001 секунд. 
* Введите команду: select from users 
  * | ID | name | age | 
  * | 1 | Ivan | 25 |
